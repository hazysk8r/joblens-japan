# JobLens Japan

求人情報を保存・検索・管理するために開発中のWebアプリケーション。

Status: In Development

## Tech Stack
Backend
- Java 21
- Spring Boot
- JPA
- PostgreSQL
- Flyway

Frontend
- React
- TypeScript
- Vite

Testing
- JUnit 5
- MockMvc
- Testcontainers
- Vitest
- React Testing Library

## Implemented Features
- Job posting CRUD
- Keyword search
- Application status management
- Pagination
- Sorting
- Backend sort whitelist validation
- Frontend/backend automated tests

## Architecture
React
↓ REST API
Spring Boot
↓ JPA
PostgreSQL
